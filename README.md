# D++ Compiler

## Requisitos

* Java JDK 21
* Git

## Como rodar

### Linux/Mac:

```bash
chmod +x build.sh
./build.sh
```

### Windows:

```bat
build.bat
```

## Estrutura

* `grammar/` → arquivo .sablecc
* `generated/` → código gerado automaticamente
* `src/` → código Java do compilador
* `tests/` → arquivos .dpp para teste
